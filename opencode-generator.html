✨ NOUVEAU v8 — Boucle lab → but (§8.2bis Blueprint)
Le banc de lab génère désormais journal.jsonl à chaque appel, via l'Event capture wrapper. Sans ça, l'acquis "journal.jsonl" restait uniquement côté orchestrateur cible.

Modèle Ollama local pour la synthèse



Aperçu du run_agents.sh généré (v8)

#!/usr/bin/env bash
# run_agents.sh — généré par le lab v8, providers cochés en rotation
set -euo pipefail

for p in "${CHECKED_PROVIDERS[@]}"; do
  opencode run --model "$p" --format json "$TASK" \
    > "out_${p}.json" 2> "err_${p}.log"
  ec=$?
  
  # Event capture wrapper (même code que l'orchestrateur cible, §6 Blueprint)
  jq -n --arg tid "${p}" --arg prov "${p}" --argjson ec "$ec" \
    '{task_id:$tid, provider:$prov, status:(if $ec==0 then "ok" else "error" end), timestamp:(now|todate)}' \
    >> journal.jsonl
done

# Synthèse locale
ollama run "$SYNTH_MODEL" -f out_*.json
